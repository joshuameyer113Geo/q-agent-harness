# Hot memory

Rules this agent loads every session.

## Project
Public starter kit for building an agent harness: memory, guardrails, and verification for AI agents that ship software. People arrive here from my videos, so every doc is written for someone setting this up for the first time.

## Always
- Verify every factual claim against a primary source before publishing or committing a document.
- Match the voice of the existing docs: flowing sentences, no em dashes, no double dashes.
- Check that every link in a doc resolves before committing it.

## Never
- Never commit or reference secrets, keys, or env files.
- Never restructure the memory/ folder layout, docs in the wild link into it.
- Never push without being told to push.

## Escalate
- Anything that deletes files or history
- Any claim I can't verify against a primary source
- Anything the rules above don't cover
